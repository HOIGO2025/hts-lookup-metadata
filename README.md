## What it does

- Official USITC HTS search
- Exact MFN rates and duty
- Landed cost with MPF/HMF, freight, insurance
- Legacy Section 301 China, forced-labor 12.5%, Section 232 metals
- AD/CVD case matching

## Access

- Agents: MCP + x402 on Base mainnet, USDC only
- 20 free paid-tool calls per day per MCP client; prepaid API keys for more
- Import software: prepaid API key plans

## Disclaimers

Informational only. Not a customs ruling, legal, tax, or brokerage service.
Verify classification, origin, and all duties with CBP or a licensed professional.
